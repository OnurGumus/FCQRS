# Register a user with FCQRS

**[Start with the code](../get-started.html).** Register Alice and read her name back using F# or C# on .NET 10.

Then open the part you want to understand:

- [Try another registration](1-the-aggregate.html): change the name, then create a second account.
- [The query](2-running-it.html): build a view from saved events.
- [Register over HTTP](http-api.html), optional: call the same account through POST and GET endpoints.

[Task guides](../how-to/index.html) cover projections, sagas, testing, and deployment when you need them.
